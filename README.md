# Python NumPy Learning

A structured repository created while learning **NumPy** in Python. This repository contains organized examples, practice programs, and mini projects that cover the fundamental concepts of NumPy and numerical computing.

## 📌 Topics Covered

- Introduction to NumPy
- Array creation
- Array properties (`shape`, `size`, `ndim`, `dtype`)
- Indexing and slicing
- Boolean and fancy indexing
- Array operations
- Broadcasting
- Reshaping and transposing
- Statistical functions
- Linear algebra operations
